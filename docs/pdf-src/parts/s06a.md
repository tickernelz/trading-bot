
## 6.1 Defaults and principles

One YAML configuration file. API keys go through environment variables (api_key_env) or directly in the local config/config.yaml (api_key); config.yaml and .env are in .gitignore and do not enter the repo (chapter 5.5). The file is schema-validated at start; a wrong configuration means the bot does not start, rather than running on guessed values. The values below are the operator's proposed defaults, all of which can be changed by the owner.

Core rule: lowering a risk limit takes effect immediately; raising a risk limit or switching to live mode requires two-step confirmation.
