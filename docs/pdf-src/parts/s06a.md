
## 6.1 Default dan prinsip

Satu berkas konfigurasi YAML. Rahasia (API key) tidak di berkas dan tidak di repo; berkas hanya memuat referensi secret:NAMA, nilainya di penyimpanan kredensial OS (bab 5.5). Berkas divalidasi skema saat start; konfigurasi salah berarti bot tidak start, bukan jalan dengan nilai tebakan. Nilai di bawah adalah default usulan Wira, semuanya bisa diubah Zhafron.

Aturan inti: menurunkan batas risiko berlaku langsung; menaikkan batas risiko atau pindah ke mode live butuh konfirmasi dua langkah.
